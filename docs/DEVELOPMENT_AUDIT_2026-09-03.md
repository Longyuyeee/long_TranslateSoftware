## 产品能力现状

### 桌面端

翻译、OCR、TTS、术语表、生词本、FSRS、Anki、备份、WebDAV、单实例、托盘和自动更新已形成可用闭环。v0.5.3 的导航、页面布局、响应式表现和版本展示已经随稳定版发布。

### 浏览器扩展

Manifest V3 扩展、Native Messaging Host、桌面私有 IPC、配对授权以及 `translate`、`cancel`、`add_word` 已接通。扩展使用 `activeTab` 按需注入，不声明持久网站权限；当前通过固定开发 ID 和 Release ZIP 分发，正式商店 ID 与上架流程尚未完成。

### DOCX

安全导入、Checkpoint 恢复、有界翻译队列、安全重试、译文版/双语版重建、发布前取消和原子导出已经完成。5 份公开真实 DOCX 已通过 LibreOffice 与 WPS Office 双模式逐页验收。Microsoft Word 身份、微软签名和 COM 探针通过，但 Office 未激活，因此同批 10 份成品的 Word 正式验收尚未执行。

### PDF

文本型 PDF 的解析、翻译、恢复和 DOCX 导出链路已经完成，并通过真实模型取消/恢复和 LibreOffice 成品视觉矩阵。当前新增的复杂定位文本列检测用于暴露预览顺序风险，不代表已经能够还原任意多栏、表格或复杂排版。扫描型 PDF OCR 仍属于独立后续范围。

### 发布与安装

v0.5.3 的正式 NSIS、MSI、Updater 签名、`latest.json`、扩展 ZIP 和质量报告已经发布并复核。历史版本的真实安装、卸载、原位升级和应用内更新已经通过；当前开发分支尚未形成新的版本发布。

## 未完成事项与风险

1. **Microsoft Word 正式验收**：需要先激活有效 Microsoft 365 许可证，再执行 `npm run audit:docx:word` 和同批 10 份成品逐页检查。在完成前必须保留“Word 未验证”声明。
2. **Chrome 真实运行时验收**：当前机器未安装 Chrome。安装后应执行与 Edge 相同的扩展运行时矩阵，不能用 Edge 结果代替。
3. **正式 Authenticode 签名**：后续发布需要可用签名证书与受控密钥环境。
4. **浏览器商店发布**：需要正式扩展 ID、商店账号、隐私资料和平台审核，不属于常规代码增量。
5. **全新 Windows VM 覆盖**：仍需在无历史状态的系统上复核安装、Native Host 注册、升级和卸载清理。
6. **PDF 能力边界**：复杂多栏、表格、浮动元素和扫描件仍需更多真实语料；当前警告机制只提示风险，不保证视觉重建。
7. **主包余量**：桌面最大 chunk 已使用约 85.5% 的 300 KiB 门槛，后续功能不得在无包体审计的情况下继续扩大主包。

## 建议开发顺序

1. 对 `codex/development-roadmap-20260903` 发起评审并运行远端 CI，通过后合并到 `master`。
2. 在具备有效许可证的环境中完成 Microsoft Word 同批文档验收，单独记录结果，不夹带功能修改。
3. 安装 Chrome 后补齐与 Edge 对等的真实扩展运行时验收。
4. 收集浏览器扩展、PDF 和 Word 翻译的真实使用反馈，优先处理能够复现的内容顺序、导出差异和交互故障。
5. 扩充固定来源、固定哈希的多栏与复杂内容流 PDF 语料，根据预览和成品差异小步修正；扫描件 OCR 另行立项。
6. 将 Authenticode、浏览器商店上架和全新 Windows VM 验收分别作为独立发布任务推进。
7. 上述门禁完成且没有新增 P0/P1 回归后，再确定下一版本号与发布范围。
