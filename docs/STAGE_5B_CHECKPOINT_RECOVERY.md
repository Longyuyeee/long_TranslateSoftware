# 阶段 5B：Checkpoint 恢复入口

更新日期：2026-08-14

本增量补齐应用重启后的 Checkpoint 发现与显式加载入口。Rust 只向界面返回任务 ID、文件名、恢复后阶段、输出模式、分段计数和更新时间，最多 100 条；文件路径、正文、译文、模型地址、提示词、术语表和原始错误均不进入摘要。

工作台会自动检查本机可恢复任务，并允许用户显式加载完整 Checkpoint。加载只恢复本机状态，不会自动发送网络请求，也不会创建输出文件。损坏、未来版本、目录不匹配和非恢复终态不会进入列表；只读发现不会隔离或删除这些文件，既有显式加载与清理边界保持不变。

下一增量只接“按当前配置校验后继续 ready 任务 / 只重试失败段”，随后再把取消贯穿到 DOCX 重建和原子发布。PDF、发布版本提升和无关优化不混入本阶段。
