# Long翻译 v0.4.3 — 启动与界面体验修复

本版本集中修复应用启动、系统托盘、低高度窗口适配和通知状态问题，让首次使用与日常唤醒行为更加直观可靠。

## 本次更新

- 启用桌面端单实例保护，连续点击快捷方式不会再产生多个进程或多个托盘图标。
- 再次手动启动应用时，会显示、取消最小化并聚焦已有主窗口。
- 首次手动启动直接显示主界面；带 `--autostart` 参数的开机自启继续保持静默托盘模式。
- 为主窗口设置合理的最低尺寸，并改善低高度窗口下的侧栏滚动、标题栏、内容间距和统计信息布局。
- 通知角标改为独立未读数量，打开通知面板后立即清零。
- 通知支持逐条移除、全部清除及点击面板外部关闭，同时修复空通知面板残留打开状态的问题。

## 自动更新

v0.4.1 及更高版本用户可直接在软件内检查并安装本版本。应用会在安装前验证更新包签名，并在安装完成后重新启动。

推荐下载 `LongTranslate_0.4.3_x64_setup.exe`。由于安装包暂未购买 Windows 商业代码签名证书，首次运行时仍可能出现 SmartScreen 提示；这与应用内部用于验证更新完整性的 Updater 签名是两套机制。
