# Long翻译 v0.4.2 — 品牌图标焕新

本版本为 Long翻译启用全新的扁平化品牌图标，并统一更新所有应用与安装程序图标资源。

## 本次更新

- 以清晰的 `L` 形作为核心轮廓，提升任务栏、托盘和桌面快捷方式中的辨识度。
- 将两块语言对话框通过连续 S 曲线相互咬合，以阴阳式结构表达语言转换与融合。
- 使用冷白与亮蓝构成主体，以琥珀橙和珊瑚橙双向箭头强化翻译语义。
- 缩小并平衡左右对话框尾巴，使图形在视觉重量上更加对称。
- 重新生成 Windows ICO、Appx、macOS ICNS、Android 与 iOS 全尺寸图标资源。
- 将前端、Rust 与 Tauri 配置版本统一升级至 `0.4.2`。

## 自动更新

v0.4.1 用户可直接在软件内检查并安装本版本。v0.4.0 及更早版本仍需先手动安装 v0.4.1 或更新版本，才能进入签名自动更新通道。

推荐下载 `LongTranslate_0.4.2_x64_setup.exe`。由于安装包暂未购买 Windows 商业代码签名证书，首次运行时仍可能出现 SmartScreen 提示；这与应用内部用于验证更新完整性的 Updater 签名是两套机制。
