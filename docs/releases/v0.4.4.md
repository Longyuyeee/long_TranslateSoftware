# Long翻译 v0.4.4 — 多语言与主题界面优化

本版本集中统一下拉选择器的视觉与交互体验，完善中英文界面适配，并修复窄窗口下的局部布局问题。

## 本次更新

- 将设置、批量翻译、OCR 与生词本中的所有原生下拉框替换为统一的主题化选择器。
- 下拉菜单完整适配深色与浅色主题，支持当前强调色、键盘选择、自动向上或向下展开及长列表滚动。
- 补齐 30 种翻译语言名称、界面设置说明、状态信息、错误通知和备份提示的中英文文案。
- 修复切换界面语言后，快捷键错误及配置导入通知仍沿用启动时语言的问题。
- 修复生词本输入提示和分析状态显示为模板文本的问题。
- 优化低宽度窗口下批量翻译操作区、生词本搜索与排序区域的布局，避免控件被压缩或裁切。

## 自动更新

v0.4.1 及更高版本用户可直接在软件内检查并安装本版本。应用会在安装前验证更新包签名，并在安装完成后重新启动。

推荐下载 `LongTranslate_0.4.4_x64_setup.exe`。由于安装包暂未购买 Windows 商业代码签名证书，首次运行时仍可能出现 SmartScreen 提示；这与应用内部用于验证更新完整性的 Updater 签名是两套机制。
