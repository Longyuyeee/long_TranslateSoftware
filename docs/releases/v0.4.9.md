# v0.4.9 架构与桌面可靠性收口

本版本聚焦桌面启动、托盘、通知、纵向布局、多语言与主题一致性，并完成前后端核心边界拆分，为后续浏览器扩展 Native Host 奠定稳定基础。

候选构建哈希、签名与 Windows 交互烟雾记录见 `docs/releases/v0.4.9-candidate.md`。

## 桌面体验

- 手动启动时默认恢复、取消最小化并聚焦主窗口；开机自启动仍保持仅进入托盘。
- 单实例回调、托盘入口和重复启动统一恢复同一主窗口，避免出现多个进程或托盘图标。
- 通知面板打开后清除未读角标，删除最后一条或全部清除时同步关闭面板。
- 改善较矮窗口中的纵向布局、滚动和可操作区域。

## 多语言、主题与界面

- 补齐中英文深层键、占位符和用户可见文本自动门禁。
- 通用设置中的快捷键、WebDAV 与维护区块完成拆分。
- 下拉框统一使用主题化组件，保持明暗主题和键盘交互一致。
- 历史、生词本、术语表、模型、外观、批量翻译等页面按需加载，最大生产 JavaScript 块保持在 300 KiB 门槛内。

## 翻译与数据可靠性

- 翻译传输、单次任务、主备模型切换、双模型对比、TTS 和缓存职责拆分为独立模块。
- 生词本查询、上下文和 CSV/JSON 导出迁入独立 Rust 边界；翻译计数使用 SQLite 原子更新。
- OCR 命令支持原始 Base64 与 Data URL，并拒绝空文本、零尺寸和坐标溢出请求。
- 诊断导出保持脱敏，只包含版本、配置状态和记录数量。

## 架构与错误处理

- Rust 主入口仅保留应用壳、模块注册和数据迁移，不再直接定义领域命令。
- 应用统计、OCR 与诊断命令使用稳定的 `code + message` 错误结构；前端继续兼容旧字符串错误。
- Native Messaging v1 Schema 与双端模型已经定义，但本版本不包含可运行的 Native Host 或浏览器扩展。

## 升级说明

- 本版本不修改数据库结构，现有设置、生词本、复习进度、翻译历史、备份和 WebDAV 配置保持兼容。
- 已使用 GitHub 正式 v0.4.8 NSIS 安装包完成原位升级验证；升级后版本、单实例、主窗口、统计数据和开机自启注册项均符合预期。
- 自动更新继续使用与 `v0.4.8` 相同的签名公钥。
- Tauri Updater 签名用于验证更新包真实性，不等同于 Windows Authenticode；未配置代码签名证书时仍可能出现 SmartScreen 提示。
