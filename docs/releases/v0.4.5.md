# v0.4.5 安全存储与质量收口

本版本集中打磨现有功能的安全性、更新体验和工程可靠性，没有扩展新的产品方向。

## 安全与同步

- API 密钥、备用模型密钥、TTS 密钥和 WebDAV 密码改由 Windows DPAPI 保护，并绑定当前 Windows 用户。
- 旧版明文或 `ENC:` 敏感配置会在首次读取时自动迁移，无需手工重新填写。
- 修复 WebDAV 同步误把数据库密文当作认证密码的问题。
- 加密备份仍保持跨电脑可迁移；导入后会在新电脑上重新使用当地 Windows 用户密钥保护敏感配置。

## 更新与交互

- 更新弹窗打开时自动聚焦主操作，非下载/安装状态可按 `Esc` 关闭。
- 更新检查、下载、进度和安装状态从主界面拆分为独立流程，降低后续维护风险。
- 主题选择器补齐键盘循环选择、关闭行为与可访问语义回归测试。

## 稳定性与发布

- 可恢复的事件广播、音频缓存、系统时间和互斥锁错误不再直接导致应用崩溃。
- 新增持续集成：前端测试、依赖漏洞审计、生产构建、Rust 测试和严格 Clippy 均为必过门槛。
- Release 正文自动读取当前版本文档，避免版本说明复制遗漏或内容过期。
- 自动化验收现为前端 7 个测试文件 / 21 项测试，Rust 7 项测试。

应用内更新会在安装前强制验证更新包签名。
