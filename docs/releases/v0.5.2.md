# v0.5.2 PDF 文档翻译预览版

本版本为带可选择文本层的 PDF 提供安全、可恢复的翻译预览闭环，并把结果导出为译文版或双语版 DOCX。PDF 阅读顺序来自内容流推断，正式使用前仍应检查预览和最终排版。

## PDF 翻译工作台

- 选择未加密且带文本层的 `.pdf` 后，先查看页数、分段、文本量、结构警告和推断阅读顺序。
- 用户明确选择译文版或双语版 DOCX、目标位置并确认冻结配置后，才会发送正文给已配置的模型服务商。
- PDF 复用现有 Checkpoint、有界翻译队列、取消、失败隔离和失败段重试，不保存 API Key，也不建立第二套调度器。
- 导出前重新校验源文件 SHA-256、页码、分段位置和原文；通过不覆盖原子提交发布，成功、失败或取消均不修改源 PDF。

## 格式可靠性修正

- 提示词强制保留数字、日期、百分比、URL、占位符、代码、XML/HTML 和 Markdown 标记，自定义提示词同样不能绕过这些约束。
- 文档队列在模型请求前临时保护独立数字标记，收到结果后精确恢复并再次执行格式质量门禁。
- 模型偶发返回不满足格式约束的结果时会在既有上限内重试；成功分段不会因恢复或失败段重试而重复发送。
- 修正数字紧邻中文时的误判，同时防止 `1` 被更长的 `10` 冒充。

## 真实验收证据

- 4 份公开 PDF 共 43 页再次通过生产解析路径，页数、正文量、关键文本和 SHA-256 与记录一致，0 个 Unicode 替换字符。
- 使用实际保存的模型配置完成真实 PDF 翻译；36 段任务强制结束后从 Checkpoint 恢复，只继续未完成/失败分段，最终 36/36 成功。
- 36 段任务在 1 个真实请求进行中时取消，活动请求归零，未生成输出，源文件 SHA-256 不变。
- 真实模型生成的单语、双语与 12 页恢复样本共 15 页经 LibreOffice 渲染并逐页检查，无裁切、重叠、缺字或内部占位符泄漏。

## 已知限制

- 首版不支持扫描件 OCR、密码 PDF、像素级版式还原、多栏自动重排、公式、手写内容或原 PDF 回写。
- PDF 内容流顺序不一定等同于视觉阅读顺序；多栏或图文复杂文档必须先检查预览。
- DOCX 与 PDF 功能均为预览能力。Microsoft Word 16.x/365 的完整兼容矩阵尚未完成，不宣称 Word 全面兼容。
- 翻译质量取决于用户配置的模型、语言、提示词和术语表；重要文件应使用副本并检查最终成品。
