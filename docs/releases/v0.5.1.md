# v0.5.1 DOCX 文档翻译预览版

本版本新增 DOCX 文档翻译预览能力，重点完成安全导入、可恢复翻译、译文/双语重建和不覆盖原文件的可靠导出。该能力已通过 WPS Office 与 LibreOffice 真实文档验收；Microsoft Word 尚未完成正式兼容验收，请先使用副本处理重要文档并检查最终排版。

## DOCX 翻译工作台

- 选择未加密的 Open XML `.docx` 文件后，先检查结构警告、段落数量、文本工作量和只读预览。
- 支持纯译文与双语两种输出模式；输出位置必须由用户明确选择，不允许覆盖源文件或既有目标。
- 文档翻译复用现有模型、语言、提示词与术语表配置；正文只发送给用户已经配置的模型服务商。
- 工作台展示有界进度、失败段、取消、恢复和安全重试状态，不向界面暴露完整路径、API Key 或模型原始错误。

## 恢复、重建与导出安全

- Checkpoint 使用版本化白名单和任务私有目录，保存的任务状态不包含 API Key；崩溃恢复只重试未完成或允许重试的分段。
- 翻译队列具有并发上限、精确取消、失败隔离和有上限退避；永久错误会快速失败。
- 重建前再次校验源文件 SHA-256、分段锚点、ZIP/XML 和资源上限，拒绝源文件变化或不完整翻译。
- 输出通过同卷临时文件、落盘复核和不覆盖原子提交发布；成功、失败和取消均不修改源文件。

## 真实文档兼容性证据

- 5 份来自公开官方模板页的真实 DOCX 分别生成译文版和双语版，共 10 份成品，结构 round-trip 全部通过且输入 SHA-256 不变。
- LibreOffice 26.2.5.2 导出共 97 页，WPS Office 12.1.0.28043 导出共 96 页；逐页检查未发现空白页、黑块、正文截断、结构破坏或拉丁单词跨 Run 拆分。
- 两个排版引擎存在正常分页差异；内容完整不等同于像素级布局一致。

## 已知限制

- 本功能是预览能力。Microsoft Word 16.x/365 的同批 10 份真实文档矩阵尚未完成，因此本版本不宣称 Microsoft Word 全面兼容。
- 不支持旧 `.doc`、加密 DOCX、宏执行，以及无法安全映射的公式、修订、文本框等复杂结构；检测到的降级会在导入警告中显示。
- 输入上限为 50 MiB，并受条目数、解压大小、压缩比、XML、段落和总文本资源上限保护。
- 翻译质量取决于用户配置的模型、提示词、语言和术语表。正式交付前应在目标办公软件中逐页检查输出。

## 升级与发布资产

- 数据库结构和现有翻译、OCR、TTS、术语表、生词本、复习、备份、WebDAV 与浏览器桥接协议保持兼容。
- 正式 Release 继续提供 NSIS、MSI、两个 Updater 签名、`latest.json`、浏览器扩展 ZIP 和质量报告。
- 官方 v0.5.0 到 v0.5.1 NSIS 候选的原位升级已完成本机验收，用户数据库和浏览器桥接保持兼容。
- `latest.json` 在线识别和正式资产完整性依赖标签触发的 Release 工作流，将在资产发布后立即复核；若失败则撤回 Release，不把未通过资产继续作为稳定版分发。
