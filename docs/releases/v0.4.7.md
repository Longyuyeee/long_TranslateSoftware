# v0.4.7 WebDAV 可靠性与诊断

本版本重点提升多设备生词本同步的可解释性、安全性和兼容性，为后续浏览器扩展与桌面端共享生词本打好数据基础。

## WebDAV 连接与错误提示

- 设置页增加独立连接测试，并显示连接延迟。
- 认证失败、权限不足、路径不存在、协议不支持、超时、离线、服务器故障和远端数据损坏会显示对应的中英文提示。
- 最近一次同步会展示新增、更新和上传条目数量。

## 多设备同步保护

- 已有远端快照使用 ETag 条件写入；首次同步使用仅在文件不存在时写入的条件。
- 当另一台设备在本次同步期间修改云端内容时，软件会提示冲突并要求重试，不再静默覆盖较新的远端快照。
- 修复旧数据库中音标、释义或分析字段为空时同步可能失败的问题。

## 工程质量

- WebDAV 实现从主入口拆分为独立 Rust 模块。
- 翻译历史与翻译记忆从主入口拆分为独立 Rust 模块，保持前端命令兼容；查询限制为每次 1～500 条，并补充分页、删除、清空和缓存上下文隔离测试。
- FSRS 调度、到期卡片和学习统计拆分为独立复习模块；评分通过事务原子提交，到期查询和评分参数具备固定边界，删除词条不再计入连续复习天数。
- TTS 与音频缓存从主入口拆分为独立 Rust 模块；空音频不会写入或命中缓存，普通 HTTP 语音请求拒绝非成功响应，并补充请求构造、缓存键和容量回收测试。
- 加密备份导入/导出从主入口拆分为独立 Rust 模块，保持 `.TLong` 与历史版本解密兼容；导入会在数据库替换前校验结构，空密码或无效备份不会清空现有数据。
- 高级设置增加脱敏诊断 JSON 导出，仅记录版本、配置状态和数据量，不读取或写入密钥、密码、私有地址、提示词、词条、上下文、原文和译文。
- 增加诊断泄漏测试，以唯一标记覆盖配置、历史、翻译记忆、术语表、生词本和收藏上下文，确保报告只包含聚合统计。
- 增加隔离 WebDAV 服务测试，覆盖连接成功、认证失败、URL 安全校验、条件上传、并发冲突、远端/本地合并和上下文同步。
- WebDAV 开关改为可通过键盘操作的标准开关，并完成中英文、深色与浅色主题检查。
- 生词本改为后端分页、检索和排序，默认每次加载 100 条，避免一次把全部记录和上下文送入界面。
- 增加一万条生词的首屏加载和搜索性能基线，并覆盖排序、分页与通配符搜索。
- 更新弹窗和 OCR 确认弹窗支持焦点循环、Escape 关闭及关闭后的焦点恢复。
- 主导航支持方向键、Home、End 和 Ctrl+1～7，并补充导航区域与当前页面语义。
- 前端命令、启动、托盘、Anki 导出、WebDAV 目录创建和 Edge TTS 请求构造改为显式错误，不再因可恢复异常触发生产态 panic。

## 翻译质量门槛

- 增加固定格式保持评测集，覆盖术语、数字、URL、占位符、Markdown、XML、行内代码和长上下文。
- 缓存译文缺少必要内容时不再直接复用；主模型破坏格式时自动切换备用模型。
- 主备模型均未通过校验时返回明确错误，并阻止无效译文写入缓存。

## 语音质量夹具

- 固定验证中、英、日、韩、俄、阿文本的语言/地区路由，以及配置音色、默认音色和降级原因。
- 识别 MP3、WAV、Ogg、M4A、WebM 和 AAC 音频容器，避免把常见服务错误正文交给播放器。
- 音频无法解码时返回稳定错误说明，不再直接透出浏览器实现相关异常。

## OCR 语言与质量基线

- OCR 设置优先显示 Windows 实际安装的识别语言，枚举失败时继续使用内置列表。
- 旧版本保存的 `en`、`zh-Hans` 等短标签会匹配本机对应的完整语言标签，不支持的选项安全回到系统默认。
- 增加字符错误率计算和五类文本基线。
- 自动生成小字号、深色字幕和缩放 PNG，并由真实 Windows OCR 识别；任一场景 CER 超过 20% 会阻断质量检查。

## 统一质量报告

- CI 汇总翻译格式、TTS 路由/音频、OCR 文本和真实 PNG 识别结果，生成包含期望值、实测值和阈值的 JSON。
- 报告作为 GitHub Actions artifact 保留；正式发版还会附加到对应 GitHub Release。
- 真机 OCR 报告缺失或任一质量门槛失败时，构建不会进入交付阶段。

## 升级说明

- 本版本不修改数据库结构。
- 现有生词本、复习进度、WebDAV 设置和加密密码保持兼容。
