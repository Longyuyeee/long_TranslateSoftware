# Long翻译 v0.4.1 — 安全自动更新

这是 Long翻译首个具备完整签名更新链路的桥接版本。

## 本次更新

- 启动后静默检测新版本，也可以在设置页手动检查。
- 新增更新弹窗，展示版本说明、下载进度、安装状态和失败重试。
- 更新包必须通过 minisign 签名校验后才能安装。
- Windows 使用被动安装模式，安装完成后自动重启应用。
- 新增自动发布工作流，统一生成安装包、签名文件和 `latest.json`。

## 首次使用说明

v0.4.0 及更早版本尚未内置本次更新公钥，无法直接自动升级。请手动下载安装 v0.4.1 一次；从 v0.4.1 开始，后续版本即可在软件内完成安全更新。

推荐下载 `LongTranslate_0.4.1_x64_setup.exe`。由于安装包暂未购买 Windows 商业代码签名证书，首次运行时仍可能出现 SmartScreen 提示；这与应用内部用于防止更新包被篡改的 Updater 签名是两套机制。
