# v0.4.6 识别与表达精度优化

本版本继续打磨现有翻译、OCR 和语音能力，重点改善小字号截图、术语翻译、缓存准确性以及英语和多语种朗读体验。

## OCR 与语言适配

- 截图识别增加自适应放大、灰度、对比度与锐度增强。
- 原始图像和增强图像会分别识别，并自动选择质量更高的结果。
- 当识别结果过弱时，自动追加二值化识别，改善暗色字幕、低对比度界面和小字号文字。
- OCR 语言选项扩展至约 30 种；识别仍在 Windows 本地完成，实际可用语言取决于系统已安装的 OCR 语言包。

## 翻译准确性

- 翻译缓存加入服务地址、模型、源语言、目标语言、提示词版本和术语表指纹。
- 更换模型、提示词或术语后，不再错误复用旧缓存译文。
- 术语表只注入原文实际命中的词条，支持英文词边界、去重与数量限制。
- 默认翻译提示词强化段落、换行、列表、数字、URL、占位符、专名、语气和正式程度保真。
- 原文使用明确边界隔离，并要求模型将其作为数据处理，降低原文内容干扰翻译指令的风险。

## 英语与多语种语音

- 设置页开放 Edge 智能语音。
- 自动识别中、英、日、韩、俄语和阿拉伯语文字，并选择匹配语言的默认音色。
- 修复 Edge SSML 固定使用中文区域、语速设置不生效和缓存未区分语速的问题。
- 增强 SSML 转义和空音频检查，语音播放失败时显示明确提示。
- 原“本地语音”更名为“免费网络”，如实反映其网络服务属性。

## 升级说明

- 数据库 schema 升级至 v8。
- 升级时会清理可再生成的旧翻译缓存，避免旧模型或旧术语配置产生的译文继续命中。
- 翻译历史、生词本、复习进度、术语表、设置和备份数据不受影响。

- Rust 12 项测试全部通过。
