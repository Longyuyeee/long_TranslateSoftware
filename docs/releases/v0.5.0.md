# v0.5.0 浏览器扩展 MVP

本版本交付 Chrome / Edge Manifest V3 浏览器扩展 MVP。扩展通过 Windows Native Messaging 复用桌面端翻译、生词本、模型配置与术语表，不在浏览器中保存 API Key 或桌面数据。

## 浏览器划词翻译

- 在普通网页中由用户主动启用划词翻译，刷新页面后注入自动失效。
- 选中文字后先显示轻量“译”入口，只有用户点击后才把所选文字发送给桌面端。
- 英文默认翻译为中文，含汉字文本默认翻译为英文；支持复制译文、取消任务和关闭浮层。
- 浮层使用 Shadow DOM 隔离页面样式，支持中英文、明暗主题、键盘关闭、窄视口和页面缩放。

## 桌面桥接与生词本

- 单个桌面 EXE 同时承担应用和 Native Host，通过受认证的当前用户命名管道转发请求。
- 首次连接在桌面端展示真实扩展 Origin 与申请能力，支持批准、拒绝、撤销和重新授权。
- 翻译与生词本收藏使用独立能力；旧的翻译授权不会自动获得 `wordbook` 写入权限。
- 收藏只发送所选原文和返回译文，不携带页面 URL、上下文或其他网页数据。

## 安全与稳定性

- 扩展仅申请 `nativeMessaging`、`activeTab` 和 `scripting`，不声明持久网站权限或常驻 content script。
- 未授权 Origin、未知字段、超限消息、不兼容协议、错误 request ID 和 nonce 默认拒绝。
- Host 断开、授权撤销或界面卸载会取消在途任务；同一会话保持有界并发和资源上限。
- 未配对、桌面端未运行、翻译失败和收藏失败使用本地化安全提示，不向网页暴露 Host 路径、密钥或原始诊断。

## 安装扩展

1. 安装本 Release 中的 Windows NSIS 或 MSI 桌面端。
2. 下载并解压 `LongTranslate_0.5.0_browser_extension.zip`。
3. 在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，选择“加载已解压的扩展程序”。
4. 选择解压目录，确认扩展 ID 为 `imaogjlfhfohdnngppnfhapdfkaldmkn`。
5. 打开扩展弹窗检查桌面连接并完成配对。

当前以固定开发 ID 的 ZIP 提供 MVP；Chrome Web Store 与 Edge Add-ons 正式上架不在本次 Release 内。

## 升级说明与已知风险

- 桌面数据库结构不变，现有设置、密钥、生词本、复习进度、历史、备份和 WebDAV 配置保持兼容。
- 自动更新继续使用既有 Updater 公钥；本 Release 同时发布 EXE、MSI、签名、`latest.json`、扩展 ZIP 和质量报告。
- 自动测试、真实 Edge 运行时烟雾和桌面桥接已经通过。项目负责人接受本次未执行签名候选的 Chrome/Edge 全量人工安装、升级与卸载验收风险；商店正式 ID 和上架流程后续单独处理。
- Tauri Updater 签名用于验证更新包真实性，不等同于 Windows Authenticode；未配置代码签名证书时仍可能出现 SmartScreen 提示。
