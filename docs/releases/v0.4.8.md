# v0.4.8 可量化质量与架构收口

本版本把 Long翻译从功能闭环推进到可重复审计的质量工程阶段，重点提升翻译、OCR、语音、同步和本地数据的可靠性，同时保持现有用户数据与操作习惯兼容。

## 可量化质量

- 翻译格式保持评测覆盖术语、数字、URL、占位符、Markdown、XML、行内代码和长上下文。
- 缓存或主模型译文缺少必要内容时不再直接复用，主模型校验失败会自动切换备用模型。
- TTS 夹具覆盖中、英、日、韩、俄、阿语言路由，以及 MP3、WAV、Ogg、M4A、WebM 和 AAC 音频容器。
- Windows OCR 使用自动生成的小字号、深色字幕和缩放 PNG 进行真实识别，单场景字符错误率超过 20% 会阻断交付。
- CI 和正式 Release 生成统一 JSON 质量报告，并记录期望值、实测值、阈值与提交版本。

## 同步、备份与导出

- WebDAV 增加连接测试、延迟显示、中英文结构化错误和最近同步摘要。
- 使用 ETag 条件写入保护多设备并发同步，云端变化时提示重试，不再静默覆盖较新快照。
- 加密备份在替换现有数据库前验证配置和生词本结构，错误密码或损坏文件不会清空本地数据。
- Anki APKG 导出修复动态牌组配置、字段转义、异常路径临时目录清理和静默丢行。
- 高级设置可导出脱敏诊断 JSON，不包含密钥、密码、私有地址、提示词、原文或译文。

## 交互与可访问性

- 更新弹窗和 OCR 确认弹窗支持焦点循环、Escape 关闭及关闭后的焦点恢复。
- 主导航支持方向键、Home、End 和 Ctrl+1～7，并提供当前页面与导航区域语义。
- 生词本改为后端分页、检索和排序，并建立一万条数据的首屏与搜索性能基线。
- 设置兼容旧配置键和 OCR 短语言标签；无效界面语言与字号会回到安全范围。

## 架构与回归保护

- Rust 拆分 WebDAV、生词本查询、诊断、OCR、翻译历史/记忆、复习调度、TTS/音频缓存、加密备份和 Anki 导出模块。
- 前端拆分更新、批量翻译、生词本和设置持久化流程，通过请求编号隔离过期异步响应。
- 自动化覆盖 81 项前端测试和 40 项 Rust 测试，并执行严格 Clippy、依赖安全审计和生产构建。

## 升级说明

- 本版本不修改数据库结构。
- 现有设置、生词本、复习进度、WebDAV 配置、备份密码和翻译历史保持兼容。
- 自动更新继续使用现有签名公钥；建议优先下载 NSIS 安装程序。
