# v0.5.3 桌面界面体验收口

本版本集中打磨现有功能的桌面使用体验，不扩展新的数据协议或服务权限。重点修复生词本在多词条、默认窗口和最小窗口下的布局变形，并重新整理主导航的信息架构。

## 导航与全局视觉

- 左侧导航按“翻译工作、学习管理、应用设置”分为三组，功能顺序变为：文本翻译、文档翻译、生词本、单词复习、历史记录、通用设置、模型配置、外观显示。
- `Ctrl+1~8`、方向键、Home/End 和页面切换方向与可见导航顺序保持一致。
- 统一浅色/深色背景层次、玻璃卡片边界与阴影、内容间距、紧凑高度和最小窗口内边距。
- 主窗口左下角显示实际运行版本，并与“检查更新”形成稳定的信息区。

## 生词本修复与打磨

- 将筛选/导出/添加工具栏与词条列表拆成独立布局，词条列表拥有自己的滚动容器，卡片不再因空间不足被 Flex 压缩成细线。
- `960px` 以上保持词条列表与详情双栏；更窄窗口切换为横向词条列表和纵向详情，页面自然滚动。
- 长单词、长音标、释义、词源、助记、近义词和例句在可用宽度内安全换行；删除和朗读操作保持可见。
- 详情卡片收紧无效留白，统一圆角、内边距和内容节奏。

## 其他界面修复

- 批量文本翻译改用更安全的双栏断点；主备模型对比只在宽度足够时并排，避免侧栏占用后内容被挤压。
- 模型配置和复习空状态在窄窗口使用自适应内边距。
- 8 个主页面在 `1000×700` 与应用最小支持尺寸 `820×560` 下逐页完成真实浏览器验收，页面与主内容区均无横向溢出。
- 生词本另以 8 条包含长文本、音标、助记、近义词和例句的完整词条验收：默认窗口卡片保持稳定高度并独立纵向滚动，最小窗口卡片保持固定尺寸并横向滚动。

## 兼容性与升级

- 数据库、配置、DOCX/PDF Checkpoint、OCR、TTS、生词本、复习、备份、WebDAV 和 Native Messaging v1 均保持兼容，无需数据迁移。
- PDF 与 DOCX 仍是带明确边界的预览能力；本版本不改变扫描 PDF、密码 PDF、复杂多栏阅读顺序和 Microsoft Word 正式兼容矩阵等既有限制。
- Release 继续提供 NSIS、MSI、Updater 签名、`latest.json`、浏览器扩展 ZIP 和质量报告。
