# Windows 交互桌面发布前烟雾检查

该检查用于 Windows 发布候选安装包。GitHub Runner 没有可靠交互桌面，因此以下断言必须在真实 Windows 用户会话中执行并记录。

Tauri Updater `.sig` 用于应用内更新真实性校验，不等同于 Windows Authenticode。未配置 Authenticode 时，候选安装包仍可能触发 SmartScreen。

## 环境

- 使用即将发布的 NSIS 候选安装包完成覆盖安装；
- 关闭开发版和旧版本进程；
- 保留一个可见任务栏和系统托盘；
- 记录 Windows 版本、显示器数量及缩放比例。

## 启动、单实例和托盘

1. 确认应用未运行，双击桌面快捷方式。
2. 主窗口应显示、取消最小化并获得焦点；托盘只出现一个 Long翻译图标。
3. 最小化主窗口，再次双击快捷方式。
4. 已有主窗口应恢复并聚焦；任务管理器仍只有一个应用进程，托盘仍只有一个图标。
5. 关闭主窗口。
6. 进程应继续运行，主窗口隐藏，托盘图标保留。
7. 左键点击托盘图标，再使用“显示设置”菜单各验证一次。
8. 两种入口均应恢复、取消最小化并聚焦同一主窗口。

## 开机自启

1. 在设置中启用开机自启并注销/重新登录 Windows。
2. 应用应只进入托盘，不主动显示主窗口。
3. 手动双击快捷方式后，应恢复已有实例的主窗口，不增加进程或托盘图标。
4. 关闭开机自启并再次登录，确认应用不再自动启动。

## 通知与窗口恢复

1. 触发至少两条后台通知，确认未读角标累加。
2. 打开通知面板，角标应归零。
3. 逐条删除至最后一条，面板应自动关闭。
4. 再次触发通知并使用“全部清除”，列表、角标和面板状态应同时清空。
5. 在主窗口最小化、被其他窗口遮挡和关闭到托盘三种状态下分别触发恢复。

## 记录与退出门槛

- 记录通过/失败、时间、安装包 SHA-256 和操作者；
- 任一场景出现多进程、多托盘图标、窗口未恢复或自启弹窗，阻断发布；
- 截图不得包含 API Key、WebDAV 地址、原文、译文或个人词库；
- 通过后才能创建版本标签并启动正式 Release workflow。
